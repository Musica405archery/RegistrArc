# Gestion des engagements archers
Le module permets une gestion simplifié des engagements d’une compétition sur I@nseo
Elle permet de suivre les archers inscrits, leurs engagements, leur règlement, ainsi que leur position sur le pas de tir.

## Présentation
Ce module a été conçue pour simplifier le suivi des archers pendant une compétition.
Elle permet notamment de savoir rapidement :

- quels archers sont engagés ;
- si un engagement a été réglé ;
- sur quelle cible un archer est placé ;
- quels archers ne sont pas encore affectés ;
- combien de départs sont liés à un archer.
